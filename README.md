## Установка
### Копирвание файлов
1. Вариант со скачиванием архива
    - Скачайте [весь репозиторий](https://github.com/Pankovea/Pankovea_MaxScriptsTools/archive/refs/heads/main.zip)
    - Разархивируйте в `%LOCALAPPDATA%/Autodesk/3dsMax/20XX - 64bit/ENU/`
2. Вариант со скачиванием отдельного скрипта
    - Скачайте нужный скприпт из папки usermacros и поместите его в папку `%LOCALAPPDATA%/Autodesk/3dsMax/20XX - 64bit/ENU/usermacros` (Замените `20XX - 64bit` на вашу версию 3dsmax) <a name="#individual-icons-install"></a>
    - Если понадобится, то скачайте `usericons` и поместите их в папку `./usericons`
3. Вариант через клонирование репозитория (У вас должен быть установлен [Git](https://git-scm.com/install/windows)):
    - Зайдите в вашу папку `%LOCALAPPDATA%/Autodesk/3dsMax/20XX - 64bit/ENU/` (Замените `20XX - 64bit` на вашу версию 3dsmax)
    - В строке адреса выполните
    ```
    git init
    git remote add origin https://github.com/Pankovea/Pankovea_MaxScriptsTools.git
    git checkout -b main origin/main
    ```
### Настройка пользовательского интерфейса
- Запустите/перезапустите 3dsmax
- Меню `Cutomize` -> `Cutomize user interface` -> `вкладка Toolbars`
- Если нужно, создайте новую панель `New...` -> `Pankov_scripts`
- Слева выберите `group Main UI` -> `Category #PankovScripts` -> Перетащите нужный скрипт на панель

## Simplify Spline

[Версия 2026.09.06 - alpha](/scripts/#Simplify-Spline.ms)

Скрипт для упрощения сплайнов. Обязательно базовый объект EditableSpline или Line. Модификатор EditSpline работать не будет.

В случае выделения:
* вершин, удаляет группу последовательных вершин и стремится сохранить форму.
* сегментов, производит автоматический выбор точек для удаления внутри группы смежных сегментов, оставляя его крайние точки.
* сплайнов сам определяет какие вершины можно удалить.
Так же работает на уровне объектов, но только с базовым EditableSpline.

Нужно произвести выделение объектов или подобъектов и запустить:
1. run_rebuildArcs() -- Ищет дуги окружностей и восстанавливает. Обычно для обработки CAD исхожников.
2. run_simplifySpline() -- Работает с произвольной кривизной.
(Возможен последовательный запуск)

## Rebuild Extruded Mesh to Spline
[Версия 2026.09.05 - alpha](usermacros/%23PankovScripts-Rebuild-Mesh-to-Extruded-Spline.mcr)

Восстанавливает импортированные меши, которые изначально были сплайнами с выдавливанием, в исходное состояние:
- автоматически определяет ось выдавливания по РЁБРАМ ПОЛИГОНОВ (Editable Poly)
- строит сплайн по контуру крышки (или фасада стены): проёмы (окна/двери) сохраняются
  как отверстия
- оптимизирует форму сплайна с помощью [Simplify Spline](#simplify-spline) (по желанию — Ctrl отменяет оптимизацию)
- добавляет выдавливание той же высоты
- сохраняет Material ID верхней/нижней крышки и поверхности выдавливания
  (обычный Extrude при ID по умолчанию, иначе модификатор MaterialID / Shell+UVWMap)

Как пользоваться:
1. Выделите один или несколько мешей
2. Запустите макрос `Rebuild Extruded Mesh to Spline`
3. Готово: вместо каждого меша появится сплайн с выдавливанием

Модификаторы клавиш:
* обычный запуск — ось определяется автоматически (по рёбрам полигонов);
  при неоднозначности — мировая +Z (плита)
* Shift — подсказка фоллбэка для стен/наклонных: локальная ось наименьшей протяжённости
* Alt — направление выдавливания: базовая сторона максимальная, в отрицательную
  сторону (без Alt — минимальная, в положительную)
* Ctrl — выключить автоупрощение сплайна
* Shift + Alt + Ctrl — комбинации допустимы

Исходный объект удаляется автоматически.
Глобальные настройки лежат в начале файла (REMS_*, например REMS_preserveMatIDs).

## ModPropsLister
[Версия 2026.09.06](usermacros/%23PankovScripts-ModPropsLister.mcr)

Динамический мульти-редактор параметров выделенных НЕ-ИНСТАНС объектов.
Сравнивает и правит общие свойства базового объекта и общих модификаторов
(верхний экземпляр каждого класса в стеке).

* Список модификаторов и базового объекта с иконкой-«глазом»: включён / выключен /
  смешанное состояние (смешанное — выпадающее меню Enable / Disable)
* Свиток свойств генерируется автоматически; различающиеся значения показаны
  неактивными с кнопкой «Сделать общим» и контекстным меню
  Maximum / Average / Median / Minimum / Most common
* Base: MIXED — разные базовые классы: показываются только совпадающие по имени
  и типу свойства. Таким образом можно менять общие свойства у разныз типов объектов.
* Групповой режим по правому клику на значении: Incremental (приращение) и Scale (множитель)
* Умный шаг спиннеров: 1% от величины параметра, нижняя граница — от средней
  величины свитка; Alt — точный степенной шаг; один шаг Undo на всю протяжку спиннера
* Фильтры по типу объектов: Geometry/Shapes/Light/Camera/Helpers

## InstancedEditMod
[Версия 1.0.0 (2026.08.30)](usermacros/%23PankovScripts-InstancedEditMod.mcr)

Добавляет модификатор Edit Spline / Edit Poly ИНСТАНСОМ сразу на все выделенные объекты.
Таким образом можно редактировать сразу несколько объектов. Для удобства можно сгруппировать,
но можно быстро найти и выделить инстансные обхекты если с выделенным модификатором запустить
макрос. 

* Если все опорные объекты — сплайны, добавляется Edit Spline; если есть хоть одна
  геометрия — Edit Poly (хелперы/свет/камеры в решении не участвуют)
* Edit Spline вставляется в сплайновую область (сразу под первый «конвертирующий»
  модификатор, напр. Extrude), Edit Poly — всегда на самый верх стека
* Повторный запуск ПЕРЕИСПОЛЬЗУЕТ существующий инстанс (добавляет объекты без него),
  в имя модификатора пишется " multi (N)"
* Если в стеке открыт наш multi-модификатор (или объекты разделяют общий инстанс) —
  запуск выделяет все объекты, у которых он есть (группы при необходимости открываются)
* Shift — Collapse To: наш модификатор и всё ниже него сворачиваются в базовый объект

## ResetPivotOffset
[Версия 2026.09.06](usermacros/%23PankovScripts-ResetPivotOffset.mcr)

Работает как Reset Xform, но СОХРАНЯЕТ поворот: сбрасывает смещение и масштаб
пивота (objectOffset), оставляя ориентацию осей.

* Обычный запуск: существующий модификатор "Reset Pivot XForm" подгоняется под текущее
  смещение пивота (или добавляется новый), затем offset сбрасывается
* Shift: смещение пивота «запекается» в трансформацию объекта, offset сбрасывается
  без модификатора

Пригождается после `Hierarchy → Affect Pivot Only` → `Reset Pivot only`, когда нужно
сбросить позицию/масштаб пивота, не теряя его поворота.

## Batch Views Manager
[версия 2026.10.03](usermacros/%23PankovScripts-BatchViewsManager.mcr)

Утилита для управления пакетным рендером (Batch Render).

Batch Views:
* Перемещение видов в списке, группировка видов, перемещение групп
* Быстрая загрузка вида в сцену по клику в списке (камера, разрешение, состояние сцены)
* По двойному клику Вкл/выкл видов, свернуть/равернуть группу. 
* Пресеты пропорций (3:2, 4:3, 16:9, ...) с учётом ориентации кадра
* режим **Preserve MegaPix** Позволяет изменить пропорции, сохранив количество пикселей в кадре.
* Расчёт разрешения: явно введённые значения применяются как есть; кратность (16/8) действует только на пересчитанные стороны (LOCK, Preserve MegaPix, пропорции, Мпикс)
* Масштабирование (Scale) разрешения для предварительного просмотра/финала всех видов. 
  - Базовое разрешение хранится в имени вида (`CamA (1920x1080)`), глобальный масштаб применяется как единый множитель ко всем видам
  - Кнопка **Apply** запекает текущий масштабированный размер как новую базу и сбрасывает масштаб на 100%
* Пакетное изменение выходных размеров и путей (в том числе и путей в Render Elements)

Cameras:
* Список камер. Двойной клик - отображение в видовом окне. Одинарный - редактирование в интерфесе скрипта.
* Настойка параметров объектива камеры и параметров съёмки.
* Переименование камеры с обновлением имён видов, если вид содержит название камеры.
* Поддержка камер Corona, VRay, Physical
* Кнопка «веник» — выделить в сцене камеры, не используемые ни в одном batch view

Scene States:
* Замена стандартного диалога Scene States. Всё в одном окне — создание, переименование, обновление и удаление состояний сцены.
* Быстро и удобно: меньше кликов мышкой, чем в стандартном интерфейсе.
* Выбор частей для сохранения (камера, свет, материалы, слои, окружение и т.д.), применение состояния двойным кликом, сортировка списка по имени.

## Concentric Cycles
[Версия 2024.10.12](usermacros/%23PankovScripts-ConcentricCircles.mcr)

Скрипт создаёт изменяемый объект с концентрическими окружностями с заданными параметрами

Возможности:
* объект создаётся в начале координат или в центре выделенного объёма бордюрной коробки (boundibg box)
* объекту назначаются персонализированные параметры (custom attributes), которые потом используются для изменения объекта
* если выделен один такой объект, то при открытии скрипта загружаются текующие параметры объекта. ри изменении параметров объект будет изменён
* если выделено нескоклько объектов, то параметры будут применены сразу ко всем обхектам (только ConcentricCycles)
* случае неверного задания параметров есть возможность отменить действие стандартным способом.

## Copy-Paste
[Версия 2025.03.20](usermacros/%23PankovScripts-CopyPaste.mcr)
### Работа с объектами

Добавляет кнопки копирования и вставки объектов между различнми проектами/окнами 3dsmax
Можно назначить быстрые клавиши через меню: `Customize -> Hotkey Editor -> найти Copy-Paste action -> Assign hotkey`.
Например у меня это `Alt+C` и `Alt+V`.

В случае с индивидуальной установкой требуется скопировать иконки [1](usericons/pankov_CopyPaste_24i.bmp) и [2](usericons/pankov_CopyPaste_16i.bmp) в папку `usericons` настроек вашего 3dsmax ([см. Установка п.2](#установка))
### Работа с модификаторами
Макроскрипт для назначения быстрых клавиш. Он не имеет иконок.
Вместо того чтобы выделять мышкой -> правой кнопкой -> выбирать в меню скопирование модификатора, потом тоже самое для вставки.
Можно пользоваться быстрыми клавишами: `Customize -> Hotkey Editor -> найти Copy-Paste Modifier action -> Assign hotkey`.
Например у меня это `Ctrl+Shift+C` и `Ctrl+Shift+V` - очень удобно. (но придётся удалить быструю кнопку с Chamfer Mode на EditSpline и EditPoly)

`Полезные особености:
* Можно вставлять модификатор сразу на несколько выделенных объектов. Он будет вставлен инстансом.
* Модификаторы EditPoly и EditSpline втавляются без локальных данных.
  То есть сохраняется связь инстансом для изменения группы объектов, но при этом не ломается другой объект.

### Select Modifier Instances
Для текущего выделенного модификатора находит его инстансы и выделяет все объекты его содержащие.
Активен, если у модификатора имеются инстансы.

## Crop To Atlas
Создайт атлас текстур (это когда множество текстур расположены в одном файле)

С помощью программы можно создать Атлас текстур, уменьшив при этом количество ассетов. Это делается в случае использования декора, который использует множество мелких текстур. Их можно уменьшить и объединить в один файл.
Данный скприпт:
- соберёт текстуры с выделенных объектов
- уменьшит их при необходимости
- разместит в одном или нескольких атласах компактно с помощью алгоритма MaxRects (возможен поворот)
- изменит ссылки материлов на новую текстуру-атлас
- произведёт корректную обрезку и обратный поворот (учитывает прежние координаты обрезки)

- Работает с Bitmap, CoronaBitmap, VrayBitmap

## Distribute
[Версия 2026.08.28](usermacros/%23PankovScripts-Distribute.mcr)

Скрипт для рапределения в пространстве

Особенности:
* Работает в режиме Объектов и в режиме подобъектов.

* Распределяет группированные объекты

* для запуска необходимо находиться в нужном режиме выделения.

## Mass Import Grid
[Версия 0.1 (2026.09.25)](usermacros/%23PankovScripts-MassImportGrid.mcr)

Массовый импорт ассетов: каждый файл импортируется, группируется, замеряется
и раскладывается в сетку по плоскости XY. Своего окна у макроса нет.

Как работает:
1. Сразу после запуска открывается стандартный диалог выбора файлов
   (мультивыбор, по умолчанию - все поддерживаемые форматы) - и сразу начинается
   импорт. Вместо диалога файлы можно передать напрямую, см. «Запуск без диалога».
2. Каждый файл импортируется в сцену (`*.max` - merge, `*.fbx` / `*.obj` /
   `*.dae` / `*.dwg` / `*.dxf` - импорт) и новые объекты объединяются в группу.
3. Размер группы измеряется по мировому bounding box (объединяются боксы всех
   узлов поддерева, вырожденные боксы - головы групп, точки - игнорируются).
4. Группы раскладываются в сетку по XY: колонки = `ceil(sqrt(N))`,
   **переменная ячейка** - у каждого столбца своя ширина, у каждого ряда своя
   высота (максимум по габаритам внутри них), плюс отступ в процентах.
   **Ось Z не изменяется** - меняются только X и Y.
5. Вся партия - один шаг Undo (`Undo Item: Mass Import Grid`).
6. В конце - Zoom Extents по импортированному (если включено `migZoomExtents`).

Настройки по умолчанию - локальные переменные в начале `.mcr`, правятся в файле.
Ничего никуда не записывается, `3dsMax.ini` не используется:
* **migGapPct** - свободное место вокруг объекта в процентах от его наибольшего
  габарита (по умолчанию `10.0`). Ячейка = габарит × (1 + %/100)
* **migCols** - `0` = авто (`ceil(sqrt(N))`), иначе фиксированное число
* **migAnchor** - `1` = центр габарита (по умолчанию), `2` = левый нижний угол
* **migCenterGrid** - `true`: весь блок центрируется по X/Y; `false` - от нуля
* **migNameFromFile** - переименовывать группы по имени файла
* **migSortFiles** - сортировать файлы по имени (предсказуемый порядок раскладки)
* **migZoomExtents** - `true`: после импорта показать результат во вьюпорте
  (Zoom Extents по выделенным, а выделены как раз импортированные узлы)

Запуск без диалога (из Listener или в скрипте):
```maxscript
-- папка: все поддерживаемые файлы из неё
macros.run "Pankovea_MassImportGrid" "run @\"D:\\Models\\Props\""
-- конкретные файлы
macros.run "Pankovea_MassImportGrid" "run #(\"D:\\a.fbx\", \"D:\\b.max\")"
```

Особенности:
* Если файл дал всего один объект, группа не создаётся - используется сам узел
  (и переименовывается, если включена соответствующая опция).
* `*.dwg` / `*.dxf` импортируются штатным AutoCAD-импортом 3ds Max с флагом
  `#noPrompt`, то есть без диалога настроек и с последними сохранёнными
  параметрами (масштаб/юниты/слои). Чтобы их изменить - один раз
  `Файл > Импорт` вручную и настроить AutoCAD Import. Если плагин AutoCAD
  DWG/DXF не установлен, файл попадёт в список ошибок.
* Ячейка переменная, поэтому крупный ассет растягивает только свой столбец и
  свой ряд, а не всю партию.
* Не удавшиеся файлы показываются списком в messageBox, остальные импортируются
  как обычные.
* Последняя выбранная папка хранится в глобальной переменной
  `PankovMIG_LastDir` - переживает повторный `fileIn` макроса в пределах сессии,
  но на диск не пишется. После перезапуска 3ds Max папка сбрасывается.
  Это можно увидеть в Listener: `PankovMIG_LastDir`.
* Мультивыбор сделан на .NET OpenFileDialog (родной диалог Max умеет только один
  файл). Если .NET-диалог не открылся - причина пишется в Listener
  (`[MassImport] .NET OpenFileDialog недоступен: ...`), показывается сообщение и
  включается откат на выбор папки.

## Instance All

В случае с индивидуальной установкой требуется скопировать иконки [1](usericons/pankov_instancseAll_24i.bmp) и [2](usericons/pankov_instancseAll_16i.bmp) в папку `usericons` настроек вашего 3dsmax ([см. Установка п.2](#установка))

Возможности:
* Замена любого объекта инстансом выбранного объекта
путём создания инстанса и применения исходных трансформаций, слоя, и материала в зависимости от настроек.
То есть, если были выделены часть инстансов, то невыделенная чать заменена не будет.

* Замена референс части объекта с возможность выбора уровня исходного референса

* При замене большого количества объектов (>100) отображается прогресс

Пдробнее:
1. Группа Make Instances
* Может клонировать инстансом как отдельные обекты, так и сгруппированные объекты
* Может подогнать размер нового инстанса под размер заменяемых обхектов

Извлекает reference объект из выбранного и заменяет им указанный уровень в выделенных объектах.
Этот раздел работает только в объектном режиме (когда исходный объект является геометрией, но не группой)

* верхний слой (Top) - то есть заменить объект целиком. В таком случае невыделенные инстансные объекты не будут затронуты.

* базовый объект (Base object) - заменяется только первая строка - базовый объект, на оснве которого строится стек можификаторов.
В таком случае невыделенные инстансные объекты не будут затронуты.

## Reset ModContextTM
[версия 2025.10.28](usermacros/%23PankovScripts-ResetModContextTM.mcr)
Набор включает в себя несколько макроскриптов для манипуляций с контекстной матрицей трансформаций модификатора.

Справка:

У каждого модификатора есть, так называемый, контекст преобразований. Например если мы применили модификатор к одному объекту, то контекст преобразований будет нулевой, но если модификатор применён сразу к нескольким объектам, то точка преобразований помещается в центр масс объектов. Такм образом что модификатор действет одинаково на объекты в мровом пространстве, но при этом у каждого объекта будет свой контекст. И если мы сдивнем объекты, то увидем, что контекст привязан к локальным координатам. Вот для таких случаев этот скрипт. После смещения объектов поместить контекст опять в одну точку в мировых координатах. 

### Основной макроскрипт Reset ModContextTM
Сбрасывает матрицу трансформаций в контексте модификатора к состоянию как если бы модификатор был только что применён к объектам или одному объекту.

Особенности:
* Работает с выделенным модификатором в стеке модификаторов
* при нажатом Shift сбрасывает ModContextBBox для каждого объекта в отдельности
* при нажатом Esc сбрасывает Gizmo
* при изменении точки преобразований не получается сохранить объект в изначальном положении
внимание:
* undo не работает

### Reset ResetModContextBBox
Тоже самое, только сбрасывает контекстный BBox у модификатора

### Copy ModContextTM
Копирует и вставляет матрицу трансформация для моификатора сохраняя его глобальное метоположение как в исходном объекте.

Это второй вариант совмещения контекста модификаторов подгоняя только один из них и не меняя все остальные (в отличии от предыдущего скрипта).

### TransformModContextTM
Позволяет трансформировать матрицу контекста для модификатора с помощью дополнительного Dummy объекта, выполняющего роль Gizmo
Таким образом, например,  можно использовать один зависимый инстанс модификатор UVWMap на множестве объектов и подправлять напрвление с помощью контекста.

## Align Pivot PCA
[версия 2025.12.03](usermacros/%23PankovScripts-AlignPivotPCA.mcr)

Выравнивает локальные оси вдоль длинной и короткой части геометрии объекта.

Этот скрипт анализирует геометрию выбранного объекта, вычисляет ковариационную матрицу его вершин
и находит главные компоненты (Principal Component Analysis - PCA) для определения естественной ориентации формы.

При нажатии Shift+ вызов макроскрипта происходит поиск поворота оси так, чтобы ограничивающий бокс был минимального размера. При этом ось Z остаётся неподвижной
Обычно для квадратных объектов нужно повернуть оси, а для круглых оставить как есть. Соответсвенно используйте Shift+

Если Ось Z ушла вниз, что координаты автоматически корректируется,
чтобы всегда быть ближе к +Z мировой системы координат.

Затем пивот объекта перемещается в центроид и поворачивается в соответствии с найденной системой координат,
при этом геометрия остаётся неподвижной в сцене.

Скрипт корректно работает даже при изначально смещённом пивоте благодаря точному пересчёту objectOffset-параметров. Все расчёты происходят в глобальных координатах.

Скрипт работает как с геметрией, так и со сплайнами.
